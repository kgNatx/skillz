# skillz

Just some agent skills in a place where I can get them. 
## Install

```
git clone https://github.com/kgNatx/skillz.git ~/skillz
mkdir -p ~/.claude/skills
cp -r ~/skillz/copywriter ~/.claude/skills/
```

Copy any other folder the same way. Restart Claude Code to load a new skill.

## Update

```
cd ~/skillz && git pull
cp -r ~/skillz/copywriter ~/.claude/skills/
```
